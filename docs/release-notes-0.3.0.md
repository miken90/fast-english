# Fast English 0.3.0

## Highlights
- Introduce the universal popup editor flow for a more consistent editing experience across tools.
- Improve popup stability with snap-height behavior refinements.

- Refactor the popup into a universal editor -> processing -> result flow.
- Stabilize popup sizing so the window feels less jumpy while editing and reviewing results.
